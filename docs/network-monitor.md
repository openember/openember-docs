---
title: 网络管理与观测
sidebar_position: 25
---

核心可裁剪服务 `network_manager` 提供 Linux 网卡、IPv4/IPv6、链路状态、MAC、MTU 与 64 位累计流量。产品 Web 网络页按 Ethernet、Wi-Fi 和其他接口分组显示，通过 `/network/state` 的 Link 消息接入，前端不直接访问设备或执行命令。

默认只读、不需要 root，不修改接口。增加 `--manage` 可接入已有 NetworkManager D-Bus 配置，构建需要 libglib2.0-dev。配置 `OPENEMBER_SERVICE_NETWORK_MANAGER` 后按产品 launch 编排；四足产品的 Web 选项会自动选择并构建此服务。服务参数为 `--robot`、`--connect`、`--host-id` 和 `--period-ms`（默认 1000，允许 100–10000）。

接口已启用、载波、运行状态、地址分别展示，不推断互联网可达性。可选管理后端补充 SSID、连接配置、热点角色与自动连接状态；元数据单独检查过期。采集失败显示未知；断流/离线隐藏当前数值；恢复和服务重启后采用新快照。接口列表是完整替换，允许网卡热插拔。流量是累计计数，可能随接口重建或系统重启归零。

多计算机共用机器人命名空间时，Web 用 `--host-id` 选择目标主机；主机监测与网络观测须使用同一标识。不指定时选择第一个合法主机并固定到 Web 重启。Link 观测来源检查不替代控制请求的身份认证。

配置操作通过本地 Link `/network/rpc` 异步执行，支持以太网 IPv4 DHCP/静态、Wi-Fi 扫描/连接、保存连接的自动连接开关和热点。网卡及连接均从系统发现，不硬编码 wlan0/wlan1。前端沿用 PAM 登录和同源校验，后台依赖服务账户的 NetworkManager 系统权限；部署规则样例在核心服务 config 目录。

修改当前管理接口前创建 90 秒 NetworkManager checkpoint，成功后等待 40 秒确认，未确认则恢复；重新登录同一账号可继续确认。轻量确认计时器是核心通用 `ConfirmedChange`，网络恢复动作仍由后端实现。正常退出主动恢复，异常退出由 NM 超时恢复。请求不明时不自动重试，页面提示核对当前状态。

验证记录：x86_64 与 ARM64 构建通过；私有 D-Bus 的网络配置/热点和真实 Link/HTTP 确认、超时恢复、失败结果测试通过。latent131 台架已实测 Wi-Fi 扫描和空闲网口自动连接配置的修改/恢复，未切换管理网口或使能电机。真实无线连接切换和热点启停暂未作台架验收。
